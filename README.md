# Формула.

Игра для запоминания школьных формул по математике и физике. На русском языке, без регистрации, сервера, внешних шрифтов и библиотек.

## Как открыть

Дважды нажми на **index.html** в этой папке. Сайт откроется в браузере и будет работать без интернета. Устанавливать Python, Node.js или другие программы для игры не нужно.

Важно: файлы `index.html`, `styles.css`, `formulas.js`, `core.js` и `app.js` должны оставаться в одной папке. Для переноса на другой компьютер скопируй всю папку.

## Что внутри

- **60 формул для 7–11 классов**: 30 по математике и 30 по физике.
- Выбор математики, физики или смешанной тренировки.
- **Выбери правильный** — одна правильная формула из четырёх, с объяснением после ответа.
- **Собери формулу** — составь полную формулу слева направо, как в справочнике: перетаскивай плитки с буквами, числами и знаками в ячейки. В наборе всегда есть лишние символы, которых нет в ответе. Названия функций (`sin`, `cos`, `log`, `tg`) даются целиком.
- Подходы по **5, 10 или 20 вопросов**, без ограничения времени.
- Подсказки и отдельное повторение ошибок.
- Справочник с поиском, фильтром по предмету и сложным формулам.
- Статистика ответов, точности, освоенных формул, серии активных дней и результатов последних 100 завершённых тренировок.
- Ежедневная цель — 10 ответов.
- Светлая и тёмная темы, адаптация для телефона.
- Экспорт статистики в JSON и сброс с подтверждением.

## Как работает повторение

Частота ошибок увеличивает вероятность появления формулы. Правильные ответы подряд эту вероятность постепенно уменьшают. Новые формулы также получают приоритет, поэтому тренировка не превращается только в повторение уже знакомого.

После ошибки формула по возможности возвращается **через два других вопроса**. Если вопросов до конца подхода недостаточно, повышенный приоритет сохраняется для будущих тренировок. В обычной тренировке не повторяются две последние формулы, если в выбранном наборе есть другие. В отдельной работе над единственной ошибкой эта формула может идти подряд.

Формула считается **освоенной после трёх правильных ответов подряд**. Новая ошибка снова возвращает её в зону повторения. Подсказка не снижает оценку. В обоих режимах ответы проверяются автоматически. Ранее сохранённые результаты карточек остаются в статистике и помечены в истории как архивные.

## Как собирать формулу

1. Перетаскивай символы из набора в пронумерованные ячейки — мышью или пальцем. Для повторяющихся символов есть отдельные плитки в нужном количестве.
2. Можно обойтись без перетаскивания: нажатие на символ помещает его в следующую пустую ячейку. Чтобы выбрать другую ячейку, сначала нажми на неё.
3. Нажми на заполненную ячейку или перетащи символ обратно в набор, чтобы убрать его. Перетаскивание между заполненными ячейками меняет символы местами. Новый символ из набора заменяет старый, возвращая его в набор.
4. «Очистить» возвращает все символы в набор. Подсказка не стирает сборку.
5. Когда заполнены все ячейки, нажми **«Проверить формулу»**. Проверяется порядок символов из справочника, а не произвольные алгебраически равносильные записи. После ошибки видны неверные ячейки, правильная формула и объяснение.

## Где сохраняется прогресс

В `localStorage` браузера, на этом устройстве. Прогресс сохраняется после каждого ответа, даже если подход не закончен. В историю подходов попадают только полностью завершённые тренировки.

Очистка данных браузера, другой браузер или приватный режим могут привести к потере или недоступности сохранений. Для локальных HTML-файлов правила хранения зависят от браузера; при перемещении папки сохранения могут перестать отображаться. Если браузер запрещает сохранение, сайт покажет предупреждение и продолжит работать с данными в памяти до закрытия страницы.

JSON-экспорт позволяет скачать статистику для просмотра и обработки. Автоматический импорт этой копии не предусмотрен.

Никакие данные никуда не отправляются.

## Клавиатура

- `1`–`4` — выбрать ответ в режиме «Выбери правильный».
- `Enter` — перейти дальше после ответа; в конструкторе вне кнопок — проверить заполненную формулу.
- В конструкторе используй `Tab` и `Enter`/`Пробел`: выбери ячейку, затем плитку с символом. Нажатие на заполненную ячейку убирает символ.
- `Tab` — перемещение по элементам, `Enter`/`Пробел` — обычное нажатие кнопок.

## Файлы проекта

- `index.html` — структура сайта.
- `styles.css` — оформление, мобильная и тёмная темы.
- `formulas.js` — банк формул, отвлекающие ответы, объяснения и подсказки.
- `core.js` — выбор формул, приоритет повторения и подсчёт статистики.
- `app.js` — игровой процесс, интерфейс и сохранение данных.
- `tests/browser_check.py` — автоматическая проверка в настоящем Chrome без дополнительных Python-пакетов.
- `tests/screenshots/` — скриншоты проверенных экранов.

## Проверки для разработчика

Для проверки нужен Python 3.10+ и Chrome. Игра сама по себе их не требует.

```sh
python tests/browser_check.py
```

Если Chrome установлен в другом месте:

```sh
python tests/browser_check.py "C:/путь/к/chrome.exe"
```

Проверка создаёт отдельный временный профиль браузера, не затрагивая обычные данные пользователя. Проверяет банк формул, адаптивный выбор, все 18 сочетаний предмета/режима/длины, конструктор для всех 60 формул, лишние и повторяющиеся символы, замену и перестановку плиток, настоящее перетаскивание мышью и касанием, клавиатуру, ошибки и повторение, сохранение после перезагрузки, справочник, подтверждения выхода и сброса, работу напрямую через `file://`, а также мобильную вёрстку. Тестовые ответы остаются только во временном профиле.

Для размещения в интернете достаточно загрузить пять основных файлов на любой статический хостинг. Сборка и серверная часть не нужны.
